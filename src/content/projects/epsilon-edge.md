**Epsilon Edge** is an edge inference engine with the same class of efficiency knobs as our data-center stack, tuned for constrained devices and on-prem edge deployments. It targets fast execution under varying workloads with quality control in the loop.

### Efficiency knobs

- Sparse attention
- KV cache compression
- KV offloading
- Verified algorithms
- Entropy compression
- MLP sparsification
- MLP skipping
- Speculative decoding
- Agentic long context
